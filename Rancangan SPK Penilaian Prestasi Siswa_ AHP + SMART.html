Rancangan SPK Penilaian Prestasi Siswa: Integrasi AHP + SMART

Acuan: Herdiana dkk. (2024), Implementasi Metode SMART dalam SPK Penilaian Prestasi Belajar Siswa pada SMK Mandiri. Perbedaan utama: bobot kriteria ditentukan dengan AHP, bukan ditetapkan manual.

1. Fiksasi Model (Integrasi AHP dan SMART)

1.1 Alasan integrasi

Aspek Jurnal acuan Rancangan ini
Penentuan bobot Manual (40/20/15/15/10) tanpa dasar perhitungan AHP: perbandingan berpasangan + uji konsistensi
Perankingan SMART SMART (tetap)

AHP unggul di bobot (terstruktur, ada uji konsistensi CR), sedangkan SMART sederhana dan cepat untuk menghitung nilai tiap alternatif. Keduanya saling melengkapi.

1.2 Kriteria dan tipe

Kode Kriteria Tipe Sumber data
K1 Pengetahuan Benefit Nilai rapor (dikonversi ke skor parameter)
K2 Keterampilan Benefit Nilai rapor
K3 Sikap Benefit Skor sikap
K4 Kehadiran Benefit Jumlah tanpa keterangan (dikonversi ke skor)
K5 Ekstrakurikuler Benefit Kategori keikutsertaan/prestasi

Karena semua nilai sudah dikonversi ke skor parameter (skala 20-100), semuanya bertipe benefit.

1.3 Alur model terintegrasi

flowchart TD
    A[Tentukan kriteria] --> B[Matriks perbandingan berpasangan AHP<br/>skala Saaty 1-9]
    B --> C[Hitung bobot / eigenvector]
    C --> D{CR < 0,1 ?}
    D -- Tidak --> B
    D -- Ya --> E[Bobot AHP = bobot ternormalisasi SMART]

    G --> H
    H --> I[Perankingan terbesar ke terkecil]
    I --> J[Rekomendasi siswa berprestasi]

1.4 Tahapan perhitungan

Tahap A: AHP (menentukan bobot)

  1. Susun matriks perbandingan berpasangan A (n × n), dengan a_ij dari skala Saaty 1-9 dan a_ji = 1/a_ij.

  2. Normalisasi: bagi tiap elemen dengan jumlah kolomnya.

  3. Bobot w_i = rata-rata tiap baris matriks ternormalisasi (total bobot = 1).

  4. Uji konsistensi:

    • λmax = rata-rata dari (A·w)_i / w_i
    • CI = (λmax − n) / (n − 1)
    • CR = CI / RI, konsisten jika CR < 0,1

    Nilai RI: n=3 → 0,58 | n=4 → 0,90 | n=5 → 1,12 | n=6 → 1,24

Tahap B: SMART (menilai alternatif)

  1. Normalisasi bobot: sudah terpenuhi karena bobot AHP berjumlah 1, sehingga langkah ini pada jurnal digantikan hasil AHP.
  2. Skor parameter tiap kriteria (tabel konversi pada jurnal: Tabel 3).
  3. Utility (kriteria benefit): u_j(a_i) = (c_out − c_min) / (c_max − c_min) × 100
  4. Nilai akhir: u(a_i) = Σ w_j · u_j(a_i)
  5. Ranking dari nilai akhir terbesar ke terkecil.

Catatan penting dari jurnal acuan (sebaiknya dipahami sebelum presentasi):

  • Persamaan (2) di jurnal tertulis (Cmax − Cout)/(Cmax − Cmin), yaitu bentuk untuk kriteria cost. Padahal hasil pada Tabel 5 sebenarnya memakai bentuk benefit (Cout − Cmin)/(Cmax − Cmin) dengan Cmin=20 dan Cmax=100 (contoh: skor 60 → 50; skor 70 → 62,5).
  • Angka pada abstrak (152,5; 143,75; 141,25) tidak sesuai dengan Tabel 7 (72,5; 58,75; 57,5). Gunakan angka Tabel 7 sebagai acuan verifikasi.
  • Tabel 3 bagian Pengetahuan tidak memuat rentang nilai ≥ 80, sehingga perlu dilengkapi pada sistem Anda.

1.5 Validasi model

Uji sistem dengan data jurnal (A1-A5) dengan bobot jurnal dimasukkan manual. Hasil harus sama: A1 = 55; A2 = 58,75; A3 = 56,25; A4 = 72,5; A5 = 57,5. Setelah cocok, ganti bobot dengan hasil AHP dan tunjukkan perubahan ranking sebagai bahan pembahasan (analisis sensitivitas).

2. Desain Sistem / Arsitektur Aplikasi

2.1 Arsitektur (MVC berlapis, web-based)

flowchart LR
    U[Pengguna<br/>Admin / Guru / Kepsek] --> V[View<br/>Blade/HTML + Bootstrap + Chart.js]
    V --> C[Controller]
    C --> S1[AHPService<br/>bobot + CR]
    C --> S2[SMARTService<br/>utility + nilai akhir + ranking]
    S1 --> M[Model / ORM]
    S2 --> M
    M --> DB[(MySQL)]

Logika perhitungan dipisah di Service, bukan di controller, sehingga mudah diuji dan dijelaskan.

2.2 Aktor dan hak akses

Aktor Hak akses
Admin Kelola user, kriteria, siswa, parameter
Guru / Wali kelas Input nilai siswa, lihat hasil
Kepala sekolah (pengambil keputusan) Isi perbandingan AHP, lihat ranking dan laporan

2.3 Modul dan fitur

  1. Login dan manajemen user
  2. Master kriteria (kode, nama, tipe)
  3. Modul AHP: form matriks perbandingan, hasil bobot, λmax, CI, CR, peringatan bila CR ≥ 0,1
  4. Master siswa dan periode
  5. Master parameter (rentang nilai ke skor)
  6. Input penilaian siswa
  7. Modul SMART: hitung utility, nilai akhir, ranking
  8. Dashboard grafik dan laporan cetak (PDF/Excel)

2.4 Alur pengguna

Login → tetapkan kriteria → isi perbandingan AHP → cek CR → simpan bobot → input nilai siswa → proses SMART → lihat ranking dan grafik → cetak laporan.

3.3 Contoh DDL (tabel kunci)

CREATE TABLE criteria (
  id INT AUTO_INCREMENT PRIMARY KEY,
  kode VARCHAR(5) NOT NULL UNIQUE,
  nama VARCHAR(50) NOT NULL,
  tipe ENUM('benefit','cost') NOT NULL DEFAULT 'benefit'
);

CREATE TABLE ahp_comparisons (
  id INT AUTO_INCREMENT PRIMARY KEY,
  session_id INT NOT NULL,
  criteria_a_id INT NOT NULL,
  criteria_b_id INT NOT NULL,
  nilai DECIMAL(6,3) NOT NULL,       -- skala Saaty (1/9 s.d. 9)
  UNIQUE (session_id, criteria_a_id, criteria_b_id),
  FOREIGN KEY (session_id) REFERENCES ahp_sessions(id),
  FOREIGN KEY (criteria_a_id) REFERENCES criteria(id),
  FOREIGN KEY (criteria_b_id) REFERENCES criteria(id)
);

CREATE TABLE criteria_weights (
  id INT AUTO_INCREMENT PRIMARY KEY,
  session_id INT NOT NULL,
  criteria_id INT NOT NULL,
  bobot DECIMAL(8,6) NOT NULL,
  FOREIGN KEY (session_id) REFERENCES ahp_sessions(id),
  FOREIGN KEY (criteria_id) REFERENCES criteria(id)
);
